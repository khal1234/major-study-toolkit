# 컨텍스트 예산 계획 — 매 세션 고정분 줄이기 (2026-07-27 조사)

> `docs/` 에 있으므로 `sync_common.py` 가 옮기는 **공통 정본**이다 — 열역학·공학수학이 같은 파일을 본다.

## ★★ 상태 — 「실행 계획」 1·2·4 항은 **보류다** (2026-08-14)

아래 실행 계획은 **AGENTS.md 「크기 판정」(2026-08-12, 사용자: *[발화 생략]*)로 닫혔다.**
그 판정은 *쪼개기·이관 제안을 다시 열지 말 것* 이라고 못 박았고, 근거는 **이 문서가 무거운 이유가
곧 값어치다**(절반 이상이 실사고 기록이고, 그게 없으면 다음 세션이 규칙을 무시한다)였다.
그러므로 1항(사고 경위 HTML 주석화) · 2항(`.claude/rules/` 이관) · 4항(620줄 → 200줄대)은
**실행하지 않는다.**

- **읽고 곧바로 실행에 들어가지 말 것.** 옛 머리말이 *[발화 생략]* 이라
  그대로 읽으면 **닫힌 결정을 되돌린다.** `docs/` 는 공통이라 다섯 과목이 다 이 문서를 본다.
- **살아 있는 것은 조사 결과다** — 「공식 문서에서 확인한 사실」·「토큰 환산」·「안 맞는다고 판정한 것」은
  그대로 참이고, 3항(`InstructionsLoaded` 훅)은 이미 구현돼 돌고 있다.
- **다시 여는 길은 사용자 판정 하나다.** 바깥 자료가 200줄을 권한다는 것은 **그때 이미 검토한 근거**라
  새 사유가 아니다(2026-08-14 위키독스 「클로드 코드 가이드」 06장이 같은 주장을 하는 것을 확인).

## 왜 이 문서가 있나

사용자 질문: *[발화 생략]*
실측 당시 매 세션 고정분은 **59.4k 토큰(5.9%)** 이고 그중 **지침 파일이 32.4k** 였다
(AGENTS.md 59,737자 · CLAUDE.md 2,901자 · SUBJECT.md 7,841자).

토큰 자체보다 **규칙 부패**가 문제다 — 문서가 길어질수록 규칙이 서로 경쟁하고, 실제로
"문서에만 있어서" 지켜지지 않은 전례가 AGENTS.md 안에만 6번 적혀 있다.

## 공식 문서에서 확인한 사실 (블로그가 아니라 1차 출처)

출처: <https://code.claude.com/docs/en/memory>

1. **HTML 주석은 컨텍스트를 먹지 않는다.**
   > *[발화 생략]*

   → 사고 경위·실사고 서술을 `<!-- -->` 로 감싸면 **파일에는 남고 매 세션 토큰은 0**이다.
   에이전트가 필요할 때 Read 하면 그대로 보인다. **삭제도 이동도 필요 없다.**

2. **`@import` 는 토큰을 줄이지 않는다.**
   > *[발화 생략]*

   → 현재 `CLAUDE.md → @AGENTS.md + @.claude/SUBJECT.md` 구조는 정리는 되지만 **32k 전부 매 세션 실린다.**

3. **`.claude/rules/` + `paths` 프론트매터 = 경로 스코핑.**
   ```markdown
   ---
   paths:
     - "data/**/*.json"
   ---
   ```
   `paths` 가 있는 규칙은 **그 패턴의 파일을 읽을 때만** 로드된다.
   `paths` 가 없으면 `.claude/CLAUDE.md` 와 같은 우선순위로 매 세션 로드된다.

4. **공식 권장 크기는 200줄.**
   > *[발화 생략]*

   현재 AGENTS.md 는 **~620줄**(2026-07-27 6곳 압축 후).

5. **`AGENTS.md` + `CLAUDE.md` import 구조는 공식 권장 방식 그대로다** — 바꿀 필요 없다.
   Windows 에선 심볼릭 링크 대신 import 를 쓰라는 것까지 일치한다.

6. **`InstructionsLoaded` 훅**으로 "어떤 지침 파일이 언제 왜 로드됐는지" 로그를 남길 수 있다
   — 경로 스코핑이 실제로 동작하는지 **기계로 확인**하는 수단(규칙 11).

7. **`/doctor`** (v2.1.206+) 가 CLAUDE.md 감량안을 제안한다 — 코드에서 유추 가능한 것은 자르고
   **함정·근거·관례는 남긴다.** 터미널 대화형이라 에이전트가 못 돌린다 → **사용자가 직접** 실행.

## ★★ 함정 — 이걸 모르면 규칙이 늦게 로드돼 이미 어긴 뒤가 된다

공식 문서: *[발화 생략]*

→ **파일을 읽기 전에 판단해야 하는 규칙은 절대 스코프로 내리지 않는다.**

| 내려도 되는 것 (파일을 열고 나서 필요) | 반드시 남길 것 (열기 전에 필요) |
|---|---|
| 삽화(SVG) 표준 + 하위 5절 (~117줄) | 절대 규칙 2 (무단 창작 금지) |
| 문제 설계 눈금·유형 축 (~50줄) | 절대 규칙 10 (구역 선언 — **착수 전** 이다) |
| 콘텐츠 표기 규약 (~42줄) | 절대 규칙 11 (미검증 주장 금지) |
| 워크오더 형식 | 실행 규율 전체 (승인·배치·감사 통합) |
| | 공통 vs 과목별 · 과목 병렬 작업 |

## 실행 계획 (다음 세션 첫 덩어리)

1. `<!-- -->` 로 사고 경위 감싸기 → **`/context` 로 실제 감소를 실측**한다.
   공식 문서 말이라도 재보고 쓴다(규칙 11). 특히 **import 된 AGENTS.md 에서도 stripping 이 되는지**는
   문서가 "CLAUDE.md files" 라고만 적어 확실치 않다 — 이것부터 확인.
2. 위 표의 왼쪽 열만 `.claude/rules/` 로 이동(`paths: ["data/**/*.json"]`).
3. ~~`InstructionsLoaded` 훅으로 로드 시점 로그~~ → **2026-07-28 구현 완료**:
   `.claude/hooks/instructions_log.py` (등록됨 · 회귀 `test_permission_event_hooks`).
   `.claude/hooks/.instructions_load.log` 에 `file · memory_type · load_reason` 을 한 줄씩 남긴다.
   **스코핑이 실제로 걸린 증거 = `load_reason` 이 `path_glob_match` 인 줄이다.**
   `session_start` 만 잔뜩 있고 `path_glob_match` 가 0줄이면 **스코핑이 안 걸린 것**이므로
   2단계를 되돌린다. (단 이 훅 자체가 라이브 미검증이다 — `docs/permission-prompt-ledger.md` 참조.)
4. 목표: AGENTS.md **620줄 → 200줄대**. 규칙은 하나도 삭제하지 않는다 — 주석화·스코프 이동만.
5. 회귀 테스트(`REQUIRED_AGENTS_MARKERS`)가 계속 통과하는지 확인. 스코프로 내린 절의 마커가
   AGENTS.md 에서 사라지면 그 테스트를 새 위치로 옮겨야 한다.

## 조사에서 "안 맞는다"고 판정한 것 (다시 검토하지 말 것)

- **병렬 세션 확대·fan-out** — 이 프로젝트의 병목은 AI 처리량이 아니라 **검수자 한 명의 시간**이다.
  에이전트를 늘리면 검수 대기열과 무단 창작 위험만 늘어난다.
- **슬래시 커맨드(`.claude/commands/`)** — 사용자가 명시적으로 거절(2026-07-27).
  *[발화 생략]*.
- **PR 중심 워크플로** — 과목=브랜치 구조라 `math → main` PR 은 파괴적이다(실측 `+4,512 −17,922`).

## 추가 조사 (2026-07-28 · 공식 문서 1차)

### ★ 토큰 환산 — `문자수 ÷ 4` 를 쓰지 말 것

`/doctor` 를 비롯한 일반 도구는 `chars ÷ 4` 로 토큰을 추정하는데 그건 **영어 기준**이다.
위 `/context` 실측(지침 파일 32.4k 토큰)과 실제 문자수(AGENTS 29,824 · SUBJECT 4,627 ·
CLAUDE 1,662 = **36,113자**)를 맞추면 **한국어는 약 0.9 토큰/자**다.
→ `chars ÷ 4` 는 **3.5배 과소**다. 이 문서 위쪽의 "59,737자" 류 숫자는 **바이트**이니 주의.

| 절 | 문자 | 토큰(0.9배) |
|---|---|---|
| 삽화(SVG) 표준 + 하위 5절 | 5,723 | ≈5,150 |
| 문제 설계 | 1,940 | ≈1,750 |
| 워크오더 형식 + 수용 게이트 | ~1,400 | ≈1,260 |
| 과목 개요·챕터 도입부 | 696 | ≈626 |
| 내부 링크 규칙 | 448 | ≈403 |
| **스코프로 내릴 수 있는 합계** | | **≈9,200** |

### 스킬(`.claude/skills/`)은 대안이 **아니다** — 확인 완료

<https://code.claude.com/docs/en/skills> 확인 결과 스킬 발동은 **description 매칭**뿐이고
**파일 패턴 트리거가 없다.** 문서에 *[발화 생략]* 트러블슈팅 절이 따로 있을 정도로
미발동이 알려진 문제다. → 삽화 표준처럼 **놓치면 사고**인 규칙에는 부적합하고,
`.claude/rules/` + `paths`(파일을 읽는 순간 확정 발동)를 고른 이 계획의 판단이 맞다.
덤: *[발화 생략]* — 스킬로 옮겨도
그 세션에서는 공짜가 아니다.

### 함께 들어온 훅 2개 (예산 계획과 별개지만 같은 커밋)

`PermissionRequest`(승인창 게이트) · `PermissionDenied`(거부 부류 카운트).
설계·미검증 상태는 `docs/permission-prompt-ledger.md` 12·13번 항목이 정본이다.

## ★ 압축·캐시 레버 (2026-08-14 · 공식 1차 출처로 다시 확인)

계기는 위키독스 「클로드 코드 가이드」 05·06 장인데, **거기 적힌 것을 그대로 옮기지 않고**
`code.claude.com` 에서 다시 확인했다(규칙 11). 확인한 것과 못 한 것을 갈라 적는다.

| 레버 | 무엇 | 근거 |
|---|---|---|
| `CLAUDE_CODE_AUTO_COMPACT_WINDOW` | 자동 압축이 도는 창(토큰 수). 스크립트·클라우드용이고 **명령·플래그·설정보다 우선**한다 | 공식 `model-config` |
| `/autocompact` · `claude --autocompact` | 같은 창을 세션 안에서 / 한 실행에만 바꾼다. 100K~1M | 〃 |
| `ENABLE_PROMPT_CACHING_1H=1` | 사용량 크레딧 구간에서도 **캐시 수명 1시간**을 유지한다(기본은 5분으로 떨어진다) | 공식 `costs` |
| `# Compact instructions` (CLAUDE.md) | 자동 압축이 **무엇을 남길지** 읽는 자리 | 〃 · **이 리포 `CLAUDE.md` 에 넣었다** |
| `/compact <남길 것>` | 수동 압축에 초점을 준다 | 〃 |
| `/context` · `/mcp` · `/usage` · `/insights` | 재는 자들. `/insights` 는 최근 세션을 훑어 **마찰 지점 리포트(HTML)** 를 낸다 | 〃 |
| ~~`CLAUDE_AUTOCOMPACT_PCT_OVERRIDE`~~ | 위키독스가 «백분율 override» 로 소개했으나 **공식 `model-config` 에 없다** | **미확인 — 쓰지 말 것** |

- **★ 「MCP 서버가 많으면 고정분이 커진다」는 낡았다.** 공식: *MCP 도구 정의는 기본이 지연 로드*라
  **이름만** 문맥에 들어온다. 그래도 안 쓰는 서버는 `/mcp` 로 끄는 것이 낫다.
- **★ 압축 자체가 큰 요청이다** — `/compact` 는 요약할 대화를 통째로 읽는다. 이어갈 것이 없으면
  **`/clear` 가 공짜다.** 「일찍 압축하면 항상 싸다」로 읽지 말 것.
- **실행 규율 12 에 공식 근거가 붙었다** — *[발화 생략]*. 우리 실측(cache_read 96.8%)과 같은 말이다.
- **터미널 대화형이라 에이전트가 못 돌리는 것:** `/context`·`/mcp`·`/usage`·`/insights`·`/btw`.
  그중 **`/btw` 는 답이 대화 히스토리에 안 들어가는 질문**이라, 검수 중 «이거 왜 이래?» 를 물을 때
  문맥을 안 키운다 — **사용자가 쓰는 자리다.**
