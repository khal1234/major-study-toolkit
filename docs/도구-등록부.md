# 도구 등록부 — 등록 안 된 도구는 없는 것과 같다

> **AGENTS.md 에서 여기로 내렸다 (2026-09-06).** 182줄이 매 세션 통째로 실리고 있었는데,
> 이 목록은 **부를 때 찾아보는 것**이지 파일을 열기 전에 알아야 하는 것이 아니다
> (AGENTS 「문서 배치 원칙 — 올릴 자격」·실행 규율 20).
> **새 스크립트를 짜기 전에 이 파일을 먼저 본다** — 이미 있는 도구를 못 찾아 새로 만드는 것을
> 막는 자리다. 감사는 `python tools/audit_orphan_checks.py`(`close_report` 가 부른다) —
> ⑴ buildlib 검사 중 호출자 없는 것 ⑵ `tools/` 중 어디에도 안 적힌 것.
> 예외는 `docs/orphan-checks-allow.txt` 에 사유와 함께.

**한 도구 = 한 줄이다 — 이름 · 용도 · 부르는 형태 · 「사람이 판정하는 자리」.** 왜 열렸나·실측·잠금
테스트 이름·설계 대안은 그 도구의 **독스트링**이 정본이다(고칠 때 필요한 것이지 부를 때 필요한 게 아니다).

## 감사·점검

- `audit_convention_drift.py --check=formula-learning-path --only=<과목>` — 공식·방법의 이론/예제/문항/요약 연결 후보. 의미·교재 근거는 사람이 판정하며 계약은 `docs/공식-학습-연결.md`.

- `lint_chapter.py data/<과목>/chNN.json` — 챕터 **하나만** data lint를 돈다(신설 2026-09-03).
  `build_site.py`는 과목 전체를 순회한다 · 다른 챕터를 우회하지 않는다(안 본다) ·
  전체 빌드·삽화 렌더는 여전히 `build_site.py` 몫
- `audit_refs.py` — 절·삽화 id 참조 감사. `[깨짐]` 0이어야 한다 · id 를 바꾸기 전에 돌린다
- `audit_conventions.py --class=P --chapter=chNN` — 표기 관행. 틀린 깃발은 조용히 무시된다 ·
  [L][P] 판정은 `card-overlap-verdicts.json` 에 사람이 적는다
- `audit_checks_load.py --lengths` — 이해도 답 문장 수 분포. 상한을 정하기 전에 재는 자리
- `audit_prompt_ramp.py [--lengths] [--only=<과목>] [--fail-only]` — **문항 지문의 부담**(언어·문장
  수·글자 수)이 번호를 따라 자라나. `--lengths` 는 분포만 내고 **눈금을 고르기 전에 부르는 자리**다 ·
  기본은 후보 목록이고 면제·보류를 **안 본다**(전체 빚을 보여 준다 — 막는 자는 빌드의 C54) ·
  **사람이 판정하는 자리:** 다중 소절 모델링 문항을 첫 칸으로 내릴지(소절을 지우는 일이라 사람 몫)
- `audit_objective_coverage.py <장> [--strict]` — **학습목표 위→아래 연결**(C60 의 표 보기). 대응표
  `chNN.objective-map.json` 의 분모(교재가 고른 핵심 문항) · 목표별 자가점검/교재 문제/문항 수 · basis ·
  **사람이 판정하는 자리:** 분모를 무엇으로 삼나(교재 목표 목록 > 강의자료 > 장 끝 복습) · 태그가 맞는지
- `set_objectives.py <장> <항목id>=lo1,lo2 … [--apply]` — 항목에 `objectives` 를 id 로 적는다(모르는 id·lo 면 안 씀)
- `reorder_items.py <장> practice|problems <id> … [--apply]` — 컬렉션 순서만 바꾼다(램프 역행을 풀 때)
- `declare_check_waiver.py --key= --why= [--except=] [--pending= --chapters=] [--apply]` — 새 검사를
  열 때 **아직 못 따라온 과목·챕터의 선언**을 한 번에 적는다(「새 검사는 전 과목 기본 error」의 대가) ·
  **완화가 아니라 선언 도구다** — 사유 없으면 안 쓰고, 있는 선언을 안 덮고, 지우지 않는다 ·
  파일을 다시 직렬화하지 않고 **끼워 넣는다**(한 줄 넣으려다 354줄을 바꾼 첫 판을 되돌렸다)
- `render_probe.py <과목> <chNN> [--out]` — 빌드된 장을 **자족 HTML 한 장**으로 접는다. 서버를 못
  띄우는 자리(무인 실행)에서 **렌더 육안 검수를 실제로 하기 위한** 자다 — 로컬 파일 미리보기는
  `data:` 라 `_assets/` 상대 경로가 안 풀려 뷰어가 통째로 안 붙는다 · `site/` 는 읽기만 한다 ·
  **사람이 판정하는 자리:** 화면이 원본과 같은가(글꼴 경로만 절대경로로 바꿔 준다)

## 감사(`audit_*`) ↔ 빌드 검사 대응

어느 감사가 승격됐고 어느 것이 사람 몫인지 가리는 표다.

| 감사 도구 | 빌드가 같은 것을 막나 | 남는 몫(사람) |
|---|---|---|
| `audit_orphan_checks` | — | `close_report` 가 자동 실행 |
| `audit_refs` | **예** — `xlink_target_valid`·`xlink_landing_issue`·`xlink_topic_issue` | id 를 바꿀 때 영향 범위 |
| `audit_problem_originality` | **예** — `originality_issues`(12단어 연속 일치 = error) | 판정 기록 대상 고르기 |
| `audit_problem_numbers` | **부분** — 확실한 어긋남은 **C37** | `[참고]` 층 |
| `audit_conventions` | **아니오**(K절만 C21 승격) | B·J·L·N·P 절 전부 |
| `audit_checks_load --lengths` | **예** — **C49** `check_answer_sentences` | 상한을 다시 정할지 |
| `audit_figure_balance` | **아니오** — 빌드 F1 은 하한만 본다 | 세로 균형·간격 분포 |
| `audit_symbol_intro` | **아니오** — 빌드에 그 검사가 없다 | 전부 |
| `audit_checks_load` | **아니오** — 빌드는 상한만 본다 | 절별 분포 |
| `audit_content` | **아니오**(설계상) | 사각지대 보고 |

**판정: 「아니오」를 `close_report` 로 옮기지 않는다.** 전부 사람의 판정이 필요한 성격이라 자동화하면
경보 피로가 되고, 경보 피로는 검사기를 죽인다. 표의 목적은 자동화가 아니라 "이건 이미 막히나?"에
소스 대신 여기서 답하는 것이다.
