# major-study-toolkit — AI 에이전트로 전공 교재를 「나만의 교과서」로 만드는 틀

교재 한 장을 AI 에이전트(Claude Code · Codex)가 **데이터(JSON)로 정리하고**, 빌드 스크립트가 그 데이터를
**하나의 뷰어 HTML**로 찍어 냅니다. 뷰어에는 이론 → 유도 → 예제 → 문제 풀이 → 연습문제 탭이 있습니다.
경북대 기계공학부 학생이 21과목을 이 방식으로 정리하면서 쌓은 **규칙 · 검사기 · 훅 · 도구 · 뷰어 · 글꼴**을
과목 내용만 빼고 그대로 옮겨 두었습니다.

**완성 화면 예시:** [`site/예시-공학수학1/ch01.html`](site/예시-공학수학1/ch01.html) — 공학수학 1장(1계 상미분방정식) 한 장만
실어 두었습니다. 내려받은 뒤 `site` 폴더에서 `python -m http.server` 를 켜고 브라우저로 열면 결과물이 어떤 모습인지 보입니다.

> 채팅으로 공부하면 환각이 섞이고 시간이 많이 듭니다. 책을 처음부터 읽으면 인지 부하가 큽니다.
> 이 틀은 그 중간을 노립니다. **에이전트가 교재와 대조하며 쓰고, 기계가 검사하고, 사람은 결과 화면만 검수합니다.**

## 5분 시작

**준비물:** Python 3.10 이상 · Git · [Claude Code](https://claude.com/claude-code) 또는 Codex ·
**본인이 가진** 교재 PDF(이 저장소에는 교재가 없고, 넣어서도 안 됩니다).

```bash
git clone https://github.com/khal1234/major-study-toolkit.git
cd major-study-toolkit
pip install -r requirements.txt
python setup.py --rules --skills     # 공통 작업 규칙·스킬을 ~/.claude 에 설치(이미 있으면 건너뜀)
```

설치가 끝나면 **이 폴더에서** 에이전트를 새로 엽니다(`claude` 또는 `codex`). 첫 마디는 이것 하나면 됩니다.

```
START.md 대로 시작해 줘.
```

에이전트가 `START.md` 순서대로 진행합니다. 설치 상태를 확인하고, 과목·교재·지문 언어·첫 장을 묻고,
첫 과목을 세운 뒤 첫 장을 만들어 `site/<과목>/chNN.html` 로 보여 줍니다. 브라우저로 그 파일을 열면
됩니다.

> **「깃헙에 있긴 하네」 하고 평소처럼 일하면 이 틀은 아무 효과가 없습니다.** 규칙과 검사기가
> 작동해야 원작자가 만든 자료와 같은 품질이 나옵니다. 그래서 ⑴ `CLAUDE.md`·`AGENTS.md` 머리,
> ⑵ 첫 세션 훅(`.claude/hooks/onboarding.py`), ⑶ `START.md` 세 곳에서 「이 규칙을 채택하라」고
> 에이전트에게 못박아 두었습니다. 그래도 흘려듣는 것 같으면 한 번 더 말해 주세요:
> *「이 저장소의 CLAUDE.md 를 네 작업 규칙으로 채택해. 참고 자료가 아니야.」*

### Codex · 다른 에이전트로 시작할 때

- 저장소 루트의 **`AGENTS.md`** 가 자동으로 읽힙니다. 이 파일이 상세 규칙 `CLAUDE.md` 를 가리킵니다.
- 공통 규칙을 Codex 전역에도 걸려면 `python setup.py --codex` 를 실행합니다(`~/.codex/AGENTS.md` 에 덧붙임).
- 훅(`.claude/hooks/`)은 Claude Code 에서만 돕니다. Codex 로 작업할 때는 끝낼 때마다
  `python tools/build_site.py`·`python tools/test_checks.py` 를 **직접** 돌리게 하세요.

## 두 층으로 나뉩니다

| 층 | 어디 | 무엇 |
|---|---|---|
| **학습 층** — 전공 정리 방식 | `CLAUDE.md` · `.claude/rules/` · `.claude/skills/` · `tools/` · `site/` · `docs/` | 원 프로젝트 **실사용본 그대로**입니다. 콘텐츠 규칙(교재 원문 금지·독자성·삽화 규격·표기 규약), 빌드와 내장 검사, 검사·수정 도구 180여 개, 뷰어 템플릿, 웹폰트가 들어 있습니다 |
| **시스템 층** — 에이전트와 일하는 방식 | `system/rules/` · `system/skills/` · `.claude/hooks/` | 어느 프로젝트에나 통하는 일반 규율입니다. 커밋 규약, 물을 때와 끝낼 때, 증거를 대는 법, 요청한 만큼만 하기 같은 것들입니다. `setup.py` 가 **내 컴퓨터 전체**(`~/.claude`)에 깔아서 다른 프로젝트에서도 적용됩니다 |

- **`system/rules/층0-판정선.md`**: 매 세션 자동으로 실리는 공통 판정선입니다. 채팅 말투 한 줄은 원작자
  취향이니, 설치한 뒤 `~/.claude/rules/층0-판정선.md` 에서 자기 것으로 바꾸세요.
- **`system/skills/`**: 상황이 맞을 때만 불려 오는 범용 스킬 20개입니다. 완료를 선언하기 전에 증거를
  확인하기, 여러 단계를 끝까지 하고 한 번에 보고하기, 검증자를 따로 떼기 같은 것들입니다.
- **메모리는 따로 깔지 않습니다.** Claude Code 메모리는 사람마다 대화하면서 쌓이는 것이라, 남의 메모리를
  옮겨 오면 맞지 않습니다. 원작자 메모리 가운데 **누구에게나 통하는 것은 위 판정선과 스킬로 이미 올려**
  두었습니다.

## ⚠ 권한 설정을 그대로 켜지 마세요

`.claude/settings.json` 은 **보수적 기본값**입니다. 읽기 전용 명령 몇 개만 자동으로 승인되고, 파일 편집·
스크립트 실행 같은 나머지는 매번 확인을 거칩니다. 되돌릴 수 없는 명령(`push --force`·`reset --hard` 등)은
아예 거부됩니다. 원작자가 실제로 쓰던 폭넓은 자동 승인 설정은 `.claude/settings.auto-example.json` 에
**예시로만** 두었습니다. 옮기는 순간 승인 없이 실행되는 범위가 넓어지니, 필요한 줄만 골라 가져가세요.

## ⚠ 검사기는 파이프라인을 태워야 작동합니다

`tools/buildlib/checks_*.py` 의 검사(수식 표기·삽화 기하·교재 문장과의 겹침 등)는
**`data/<과목>/chNN.json` → `python tools/build_site.py`** 경로를 지날 때만 돕니다. 이 경로 밖에서 만든
HTML은 검사를 한 번도 받지 않은 것입니다. 「시스템에 검사기가 있다」와 「이 콘텐츠가 검사받았다」는
다른 말입니다.

## 저작권 원칙 — 이 방식의 첫 번째 규칙입니다

- **교재 원문을 데이터에 옮기지 않습니다.** 자기 말로 요약하거나 변형해서만 씁니다.
  `tools/audit_problem_originality.py` 가 교재 문장과 얼마나 겹치는지 잽니다.
- 교재 PDF와 추출 텍스트는 `.gitignore` 가 커밋을 막습니다(`*.pdf`·`*_raw.txt`·`data/**/*.txt` 등).
- 만든 자료를 **공개 배포할 때**는 과목별 교재·강의자료의 이용 조건을 직접 확인하세요.

## 알아 두면 덜 헤매는 것

- **`CLAUDE.md` 는 원작자 실사용본입니다.** 21과목·배포(Vercel)·「공용 폴더」 같은 원작자 환경 이야기가
  섞여 있습니다. 「공용 폴더」 관련 훅과 도구는 그 폴더가 없으면 조용히 건너뜁니다.
- 문서와 주석에 `[발화 생략]` 이 자주 보입니다. 규칙마다 어떤 지적에서 나왔는지 원작자의 말을 인용해
  두었던 자리이고, 공개판에서는 인용만 지웠습니다. 날짜와 규칙 내용은 그대로입니다.
- `tools/test_checks.py` 는 **starter판 회귀 스위트**(10케이스)입니다. 결함을 하나 고칠 때마다 「재현 케이스 +
  고친 형태가 통과하는 케이스」를 여기에 더해 나가는 것이 `CLAUDE.md` 가 말하는 「close」입니다.
- 도구가 왜 있는지는 `docs/도구-등록부.md` 에 있습니다. 처음부터 다 읽기보다, 에이전트에게
  「이 상황에 맞는 도구가 등록부에 있나」라고 묻는 편이 빠릅니다.
- `site/fonts/` 의 글꼴은 Pretendard·나눔명조를 부분집합으로 잘라 이름을 바꾼 것입니다(OFL, 라이선스 전문
  동봉). 원작자 자료에 나온 글자만 남아 있어서, 없는 글자는 시스템 글꼴로 대신 그려집니다.
  `python tools/font_subset.py` 로 자기 자료에 맞춰 다시 뽑을 수 있습니다.

## 뺀 것

| 뺀 것 | 이유 |
|---|---|
| 과목 데이터(`data/`) · 빌드 산출물(`site/<과목>/`) | 콘텐츠입니다. 각자 만듭니다 |
| 과목 삽화 생성기(`gen_*.py`) · 정답 검산기(`verify_*_answer.py`) | 교재 내용과 정답이 좌표·수치로 들어 있습니다 |
| 강의 녹화·LMS 도구 | 학교 계정과 강의 저작권이 걸립니다 |
| 배포 스크립트(`deploy_*`·`build_home.py`) | 원작자 호스팅 계정에 묶여 있습니다 |
| 원 프로젝트 회귀 스위트(2만여 줄) · 작업 로그 · 피드백 원장 | 작업 이력이자 개인 기록입니다 |
