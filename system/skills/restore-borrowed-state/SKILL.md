# 빌린 것은 "보고 쓰기 직전"에 닫는다

출처: XSanity 세션 메모리 이관(2026-09-01).

작업 중 빌려 쓴 것(연 앱·브라우저 탭·탭 그룹·띄운 서버 등)은 **[발화 생략]**
같은 관측 불가능한 시점을 트리거로 삼지 않는다. 그 대신 **최종 보고를 쓰기 직전**
이라는, 매번 실제로 지나가는 관측 가능한 지점에 정리를 묶는다.

체크: 최종 보고를 쓰기 전에 — 이 작업 중에 연 것 중 지금부터 안 쓸 것이 있는가?
있으면 보고를 쓰기 전에 닫거나 정리하고, 그 사실을 보고에 한 줄 남긴다.
