# 밖으로 나가는 결과물은 모바일 기준이 기본

출처: 토익 세션 메모리 이관(2026-09-01) — 이 사용자를 상대하는 다른 프로젝트
배포물에도 일반적으로 적용 가능한 습관이라 전역으로 승격했다.

갤러리 글·공유용 HTML·표처럼 **밖으로 나가서 사용자가 폰으로 볼 가능성이 있는
결과물**은 기본을 데스크톱이 아니라 **모바일 폭(대략 355px)**으로 잡는다. 데스크톱
레이아웃은 사용자가 명시적으로 언급했을 때만 신경 쓴다.

체크: 지금 만드는 게 사용자가 폰에서 볼 수 있는 결과물인가? 그렇다면 좁은 화면에서
줄바꿈·표·이미지가 깨지지 않는지를 기본값으로 확인한다 — 데스크톱 폭을 기준으로
먼저 짜고 나중에 모바일을 끼워 맞추지 않는다.
