# 내가 대체한 걸 내가 치운다 — 단, 내 것만

출처: XSanity 세션 메모리 이관(2026-09-01, 두 회차에 걸쳐 정밀해진 판단).

## 규칙

**이 세션에서 내가 만든 산출물을, 같은 세션에서 내가 새 산출물로 완전히 대체했을
때만** 자율로 지운다. 그 외(사용자가 만든 것, 다른 세션이 만든 것, 완전히 대체됐다고
확신 못 하는 것, 사람의 판단이 필요한 산출물)는 지우지 않고 **낡았다고 표시만 하거나
사용자에게 알린다** — 삭제는 사용자 몫으로 남긴다.

체크:
1. 이 파일을 **내가** 만들었는가?
2. 방금 만든 새 파일이 그 내용을 **완전히** 대체하는가(부분만 겹치면 지우지 않는다)?
3. 이 세션 안에서 일어난 일인가(다른 세션이 낀 사이의 상태 변화는 모르므로 지우지
   않는다)?

셋 다 예일 때만 지운다. 하나라도 아니면 남겨 두고 낡았다는 사실만 알린다.
