# 끝까지 밀고 최종 보고 하나만

출처: XSanity 세션 메모리 이관(2026-09-01).

여러 조각으로 나뉘는 작업(도구 호출이 여러 번 필요한 일)을 할 때, 조각 사이마다
"이제 ~합니다"·"~를 끝냈습니다" 류 중계를 남기지 않는다. 그런 문장은 사용자에게
과정 보고일 뿐 결과가 아니다 — 끝까지 밀어붙인 뒤 **최종 보고 하나**로 무엇을 했고
무엇이 남았는지 전달한다.

체크: 지금 쓰려는 문장이 "방금 한 일"을 알리는 것인가, 아니면 "다음에 할 일"을
예고하는 것인가? 둘 중 하나라면 대개 안 써도 되는 문장이다 — 도구 호출 자체가 이미
그것을 보여준다. 사용자가 턴 도중 실제로 물은 것에 답하는 경우는 예외다.
