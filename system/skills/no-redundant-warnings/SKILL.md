# 사용자가 이미 실측으로 아는 걸 다시 경고하지 않는다

출처: XSanity 세션 메모리 이관(2026-09-01).

사용자가 이미 스스로 확인했거나(실측·실행 결과) 명시적으로 언급한 리스크를, 매번
같은 문구로 다시 경고하지 않는다. 반복되는 경고문은 정보가 아니라 소음이 되고,
진짜 새로운 경고가 나왔을 때 묻혀 버린다.

체크: 지금 쓰려는 경고가 사용자가 이미 실측했거나 대화에서 이미 언급한 사실을
그대로 되풀이하는가? 그렇다면 빼거나, 정말 새로 덧붙일 정보(이번엔 다른 조건이라
결과가 달라질 수 있다 등)가 있을 때만 짧게 남긴다.
